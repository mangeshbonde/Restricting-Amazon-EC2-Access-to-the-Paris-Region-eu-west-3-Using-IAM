# Restricting-Amazon-EC2-Access-to-the-Paris-Region-eu-west-3-Using-IAM
Create an IAM policy that grants an IAM user full Amazon EC2 access only when requests target the Paris  region (eu-west-3), and explicitly denies EC2 access in all other regions; then provide step-by-step  instructions to create and attach that policy using the AWS Management Console.
